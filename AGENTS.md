# Работа с Musya

Для разработки, отладки, архитектуры и ревью применяй навык musya;
найди его в списке доступных навыков и прочитай SKILL.md до работы.
При запросе только на анализ не изменяй проект. Если навык недоступен,
сообщи об этом, не выдавая обычную работу за выполненный процесс Musya.

Поставляемый пакет находится в musya/. skill.md в корне — исторический
исходный блок; сохраняй его и соответствующий блок в musya/SKILL.md.
Изменения правил направляй в основной маршрут и тематические references.

Локальная команда проверки: `python3 -B musya/scripts/check.py`.
Она требует Python 3 и Git, использует стандартную библиотеку и не
проверяет поведение самого агента. Для этого следуй
[evaluation.md](musya/references/evaluation.md). Не запускай сценарии
в рабочем дереве и не считай тесты драйвера успешными прогонами агента.

Устройство и состояние: [FOUNDATION.md](docs/engineering/FOUNDATION.md),
поведение и проверки: [FEATURE_MAP.md](docs/engineering/FEATURE_MAP.md),
решение: [musya-evaluation.md](docs/designs/musya-evaluation.md).
