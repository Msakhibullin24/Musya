# Один навык для разных проектов

Это один самостоятельный пакет. Отдельная установка для его работы не нужна. Внутренние references — части того же навыка;
агент читает их сам по этапам, пользователь их не переключает.

В Codex личные навыки обнаруживаются в `~/.agents/skills/`, проектные —
в `.agents/skills/`. Поддерживаются символические ссылки на папку навыка.
Установи пакет целиком: SKILL.md, references, agents и уведомление
о лицензии. При переносе проекта обнови ссылку, если выбрана установка
через символическую ссылку.

Для автоматического выбора оставь `allow_implicit_invocation: true`
в `agents/openai.yaml`. Это разрешает выбор по описанию, но не является
гарантией загрузки на каждый запрос. Для постоянного личного правила
добавь в глобальный `~/.codex/AGENTS.md`, сохранив имеющиеся инструкции:

```markdown
Для разработки, отладки, рефакторинга, архитектуры и код-ревью применяй
навык musya: сначала прочитай его SKILL.md и следуй единому процессу.
Найди путь в списке доступных навыков; если пакет недоступен, сообщи об
этом, не выдавая обычную работу за выполненный Musya pipeline.
Для запросов только на анализ или ревью не изменяй файлы проекта.
```

Глобальный файл относится к настройке конкретного агента. Проектные
инструкции и ограничения среды могут уточнять или ограничивать его.
В другом ассистенте нужен поддерживаемый им механизм постоянных
инструкций; копирование папки само по себе не включает её автоматически.
Навык не меняет системные разрешения и не запускается без задачи агента.

[Best practices](https://learn.chatgpt.com/guides/best-practices).
